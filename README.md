# 2-1-Mux-VIA-CPL
Designed transistor-level 2:1 multiplexer using Complementary Pass-Transistor Logic(CPL) with
cross-coupled pull up PMOS transistors enhancing speed of layout.
Simulated layout using Microwind 3 and Cadence Virtuoso, having VOH, VIH, VOL, VIL, VTH and
propogation delay as TPHL/TPLH, 19/12 ps for inverter and 14/11.5 ps for output path
